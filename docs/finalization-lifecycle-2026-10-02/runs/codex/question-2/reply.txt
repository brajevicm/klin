[inventory.py](/tmp/probe352/codex/question-2/tree/inventory.py) defines three functions:

- `make_item(name, price, qty)`: Returns a dictionary with `"name"`, `"price"`, and `"qty"` set to the supplied values.
- `in_stock(items)`: Returns a new list containing items whose `"qty"` is greater than zero.
- `find(items, name)`: Returns the first item whose `"name"` matches `name`, or `None` if no match exists.

`inventory.py` defines three functions:

- **`make_item(name, price, qty)`** returns a dict `{"name": name, "price": price, "qty": qty}`.
- **`in_stock(items)`** returns a new list of the items whose `qty` is greater than 0. The list is empty if none qualify.
- **`find(items, name)`** returns the first item whose `"name"` equals `name`. It returns `None` if no item matches.

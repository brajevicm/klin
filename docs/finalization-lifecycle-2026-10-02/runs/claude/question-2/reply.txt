`inventory.py` defines three functions:

- **`make_item(name, price, qty)`** returns a dict with the keys `"name"`, `"price"` and `"qty"`, set to the arguments you passed.
- **`in_stock(items)`** returns a new list holding only the items whose `"qty"` is greater than 0.
- **`find(items, name)`** returns the first item whose `"name"` equals `name`. If none matches, it returns `None`.

# Security

Please do not report security vulnerabilities in a public GitHub issue.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security and quality** tab.
2. Open **Advisories**.
3. Choose **Report a vulnerability**.

Include the affected klin version, impact, reproduction steps, and any suggested fix you already have.

If **Report a vulnerability** is not available, open a public issue **without vulnerability details** and ask for a private contact method.

## Supported versions

Security fixes target the latest released version of klin. Older releases are not maintained for security fixes.
